# TAPE for Homebrew

A Homebrew tap for **TAPE** — a menu-bar meeting recorder for macOS. TAPE captures system audio and microphone as separate tracks, then automatically produces a full-length mixed file plus split chunks (each ≤ 9.9 MB) ready for Gemini transcription.

## Install

```sh
brew tap SaranH8/tape
brew trust SaranH8/tape
brew install --cask tape
```

## Update

```sh
brew upgrade --cask tape
```

## License

Installing is free, but TAPE must be activated before recording: when the app asks, enter the license email + serial key you received from Saran.
